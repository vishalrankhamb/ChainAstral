# ChainAstral

ChainAstral utilizes modular, self-healing architecture and adaptive data routing processing and real-time data synchronization within a scalable framework.

ChainAstral is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainAstral.git`
2. `cd ChainAstral`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
